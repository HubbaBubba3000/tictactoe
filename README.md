# TicTacToe
консольная реализация игры крестики-нолики, написанная на С++

## Системные Требования (для сборки и запуска)
- ос Linux
- C++17 (GCC 7+ или Clang 5+)
- CMake 3.10 или выше
- Make

## Сборка и запуск
```bash
git clone https://github.com/HubbaBubba3000/tictactoe
cd tictactoe
./build
```
```bash
cd build
./tictactoe
```
